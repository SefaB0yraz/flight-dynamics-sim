# Flight Dynamics Simulator

A C++-based flight dynamics simulation project focused on aircraft pitch dynamics, PID control, and actuator behavior.

## Overview

This project explores the fundamentals of aircraft pitch control by simulating a simplified aircraft model and a feedback control system.

The simulation models the relationship between control-surface deflection, pitching moment, angular acceleration, pitch rate, and pitch angle. A PID controller adjusts the elevator command to track a target pitch angle while respecting actuator deflection limits.

The project is being developed incrementally, with an emphasis on understanding the underlying physics, control logic, and software implementation.

## Current Features

- **Pitch dynamics:** Simulates pitch angle and pitch rate over time.
- **Simplified physics model:** Calculates control, damping, and restoring moments to determine angular acceleration.
- **PID controller:** Implements proportional, integral, and derivative control.
- **Actuator saturation:** Limits the applied elevator deflection to ±10°.
- **Basic anti-windup:** Prevents the integral term from accumulating further when the actuator is saturated and the error would drive it deeper into saturation.
- **Configurable simulation:** Allows changes to the target pitch angle, PID gains, and simulation time step.

## How It Works

The simulation follows a closed-loop control process:

1. Read the aircraft's current pitch angle.
2. Calculate the pitch error relative to the target.
3. Compute the controller output using the PID algorithm.
4. Apply actuator limits to the requested elevator command.
5. Update the aircraft dynamics using the applied elevator deflection.
6. Repeat the process at each simulation step.

### Simplified Pitch Dynamics

The model calculates the net pitching moment from three components:

- **Control moment:** Generated by elevator deflection.
- **Damping moment:** Opposes pitch rate.
- **Restoring moment:** Acts toward the model's neutral pitch angle.

The net moment is divided by the model's pitch moment of inertia to calculate angular acceleration. The angular acceleration is then integrated to update pitch rate and pitch angle.

The model uses simplified, illustrative coefficients. It is intended for learning and experimentation, not as a validated representation of a real aircraft.

## Getting Started

### Prerequisites

- A C++ compiler such as GCC or Clang
- A terminal or code editor

### Build and Run

Clone the repository:

```bash
git clone https://github.com/SefaB0yraz/flight-dynamics-sim.git
cd flight-dynamics-sim
```

Compile the current source file with GCC:

```bash
g++ -std=c++17 src/Main.cpp -o flight_dynamics_sim
```

Run the simulation:

**Windows:**
```bash
flight_dynamics_sim.exe
```

**Linux/macOS:**
```bash
./flight_dynamics_sim
```

If your source file or build configuration changes, adjust the compile command accordingly.

## Project Status

**In progress.**

The current implementation focuses on single-axis pitch dynamics and PID-based pitch control. The model and controller are being refined through experiments with control gains, actuator limits, and system response.

This is an educational simulation and has not been validated against real aircraft data or intended for real-world flight control.
